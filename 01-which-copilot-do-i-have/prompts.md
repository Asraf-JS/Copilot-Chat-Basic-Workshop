# 01 - Which Copilot Do I Have?: Prompts

Two short prompts to try once you've found the green shield. Hover over a grey box and click the copy icon in its top-right corner.

---

## Part 1: Your first safe prompt

**Session:** new chat | **Grounding:** web

```
Explain in plain English what "enterprise data protection" means in Microsoft 365 Copilot Chat. What happens to a file I upload? Answer in 5 short bullet points for an office worker with no IT background.
```

---

## Part 2: What can't I do?

**Session:** same chat | **Grounding:** web

Compare the answer with the list in section 1.4 of the notes.

```
I have Copilot Chat (Basic), without a paid Microsoft 365 Copilot license. List the Copilot features I should not expect to have. Show your sources, and tell me how recent each source is.
```
