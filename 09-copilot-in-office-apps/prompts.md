# 09 - Optional: Copilot in Word and Excel: Prompts

For **M365 Copilot (Basic)** users only. Hover over a grey box and click the copy icon in its top-right corner.

---

## Part 1: Copilot in Word

**Session:** Copilot pane in Word, with the memo open | **Grounding:** the open document

```
Summarise this memo in three bullet points, and tell me which part a busy head of department is most likely to question.
```

```
Rewrite the recommendation section so it is no more than 80 words, keeps every figure exactly as it is, and states the conditions clearly. Show me the new version in the chat.
```

Independent practice:

```
List every number in this memo, with the sentence it appears in.
```

---

## Part 2: Copilot in Excel

**Session:** Copilot pane in Excel, with the comparison table open | **Grounding:** the open workbook

Workbook name (text):

```text
Laptop comparison
```

```
Which vendor has the lowest like-for-like total in this table, and by how much?
```

```
Give me a formula I can put in a new row to check that subtotal plus tax equals the grand total for each vendor, showing TRUE or FALSE. Tell me which cell to put it in.
```

If the formula returns an error:

```
Some numbers in this table are stored as text. How do I convert them to numbers?
```
